This game has many files, one of them is main.py. This file is the file that runs the game and takes action after an input from the player 
such as klicking the play button. The other files are for the elements itself. There are the positions of the elements changed (for movement) and 
then printed on the screen (rocket.py, enemies.py and bullets.py). I created settings.py to manage the sizes and colors of the game better and it 
gives me a better overwiew of it. For easier management during the game I created statistics.py. It helps with tracking and changing the score and 
the current speed of the game, that gets faster each time the player hits an enemy.

Elements source:
https://opengameart.org


The file play_button.py was created to let the game start or restart it while scoreboard.py is always shown in the lower left corner of the screen. 
It shows your current points during the game.

Font type source:
https://www.dafont.com/
